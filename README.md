# Script de Gestão de Estoque

Repositório destinado aos scripts de automação da planilha de estoque utilizados no meu estágio.

## 🚀 Funcionalidades
* **Baixa Automática:** Scripts em Google Apps Script para processar receitas de produtos.
* **Organização de Itens:** Objeto de receitas estruturado para facilitar a manutenção de componentes (Nomad, Painéis, Sensores).

## 🛠️ Tecnologias
* Google Apps Script (JavaScript)
* Google Sheets
